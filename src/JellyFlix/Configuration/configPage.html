Profiles

Each profile is a hidden Jellyfin user that can only be reached through its household's login, so watch history, Continue Watching and parental controls are tracked per profile.

10 is PG / TV-PG in the US rating system. Unrated items are always hidden from kids profiles.

Requests (Seerr or Ombi)

Search shows matching movies and shows from Seerr (Jellyseerr / Overseerr) or Ombi with a Request button.

Search

Searching by description always works with words. With an OpenAI-compatible embeddings API (Ollama, LM Studio, OpenAI) it also finds titles that are described differently.

Appearance

Seasonal artwork, accent color and curated shelves on the home page.
Buttons, backgrounds and progress bars take a subtle accent color from the selected title's artwork.

Web client updates

Checked at startup and every six hours. Only releases built for this Jellyfin version are installed.
Replaces Jellyfin's own web client with the installed Lanternfish one. Turn off to get Jellyfin's stock web client back.
